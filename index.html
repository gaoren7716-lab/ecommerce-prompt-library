① 商品链接 / SKU

      

      

      

      

      
读取走公共跨域通道拉商品页。淘宝 / 京东 / Amazon 都有登录墙和反爬，公共代理基本拉不到——这是常态，不是坏了。真正的解法是下面的书签一键抓取（用你自己的登录态，一点就复制），或直接把链接发到对话里让我读。


      

        
★ 读不到？装个书签，一键抓商品信息

        
公共代理过不了平台的登录墙，但你自己的浏览器可以。装一次，以后在商品页点一下就自动把标题、卖点、价格、店铺复制好：

        
    
          
  1. 按 Ctrl+Shift+B 显示书签栏（Edge / Chrome 一样）
    2.

    3. 
          
  3. 打开商品页 → 点书签 → 自动复制 → 回到本页粘进 ② 解析框，点「解析」
    4. 
        

        

          🔖 抓商品信息（拖我上书签栏）
          拖不动？点这里  再手动添加书签，或把商品链接发到对话里让我读
