# 电商做图提示词库 ecommerce-prompt-library

开放式电商视觉 Prompt 知识库（V3）。一张电商图 = **12 个维度叠加**的成品，不是「选一个模板」。
定位是**电商视觉生产知识库**：分类体系、行业经验、视觉模块、真实案例、质量标准、可重复执行的生产流程。

- **直接使用**：6 个验证案例 + 5 个任务模板 + 8 个高频场景预设，一键载入复制；
- **自由组合**：12 维模块像搭积木——产出类型、营销目标、行业、机位、人物、场景、材质、风格、光影、版式、平台规格、点缀；
- **组合即想象空间**：128 条目，理论组合空间 **1.49 万亿+**（页面现算）；冲突自动裁决，行业规范选中即展开；
- **批量生产**：编码工作台一个商品出五张图型（白底主图/场景化主图/卖点详情图/促销海报/种草图），每张自带冲突检查。

覆盖 12 大图片模块：商品基础展示、平台主图与商品卡、详情页、营销活动图、生活方式场景、
人物模特、创意广告、细节材质特写、信息图排版、店铺装修品牌视觉、社交种草、AI 编辑批量生产；
平台规格国内（淘宝天猫/拼多多/京东/抖音/小红书/微信小程序）与跨境（Amazon/Etsy/Shopify/Instagram/X/Facebook）共 16 条铁律。

## 快速开始

直接双击打开 `index.html`（纯静态、免依赖、免服务器），八个页签一页只回答一件事：

1. **★ 示例画廊**：45 案例（覆盖全部 14 品类 × 多种形态/风格/平台组合，各带按配方生成的 AI 代表配图）+ 5 模板卡片，共 50 张；色卡从配方风格的登记色派生，点图看详情、点编号复制配图文件名；配图不管 JPG/PNG/WebP，页面自动探测，换图刷新即读；
2. **自定义出图**：8 个高频场景预设 + **商品信息表单**（名称/卖点/人群）+ 平台铁律 chips → 成品提示词本页实时出，
   两种复制（视觉指令 / 完整版含商品保护规则与负面词）+ 🎲 随机来一张；去合成器细调是次级入口；
3. **链接出图**：粘贴商品链接 / SKU / ASIN → 公共跨域通道读取商品页（纯前端不存数据），解析出品类/平台/人群/卖点
   → **主图 + 详情长图两份词面**即出。**公共代理过不了淘宝/京东/Amazon 的登录墙（常态，页面如实说明）**——真正的解法是
   页内 **🔖 书签一键抓取**：拖到书签栏，在商品页点一下，标题/卖点/价格/店铺自动进剪贴板（用你自己的登录态，
   零请求零存储），回来粘进「粘贴解析」即出词；只粘链接不粘文案会明确报失败，不假成功；也可以把链接发到对话里让 AI 读；
4. **提示词合成器**：配方盘分步小白化——核心三步（① 产出类型 ② 品类方向 ③ 发布平台）置顶，
   其余九维收进「进阶微调」折叠区；成品区默认一张词面 + 主复制按钮，负面词/中文配方/母版/变更清单/JSON
   收进「更多格式」折叠；每维可 🔒 锁定，随机灵感只洗没锁的；变形算子一步换方案；最近灵感本机保存；
5. **抽卡**：抽 1/4/8 组没见过的组合，冲突自动规避；「随机来一张（案例）」在页内直接出卡（带配图，不动当前配方）；
6. **全部词条**（在合成器页内，配方盘下方折叠区）：128 条全量检索，点名字看详情
   （行业规范/二级目录/色卡/建议链），点「加入」直接点亮配方盘、成品即时更新；
7. **风格配色搭配**：12 张风格配色卡，点色块复制 hex，一键载入风格；
8. **框架与体检**：实时盘点 + 覆盖缺口 + 冲突裁决 + 平台规格速查（全部现算）；
9. **编码工作台**：SKU 批量出图（一商品五图型，平台/品类/风格/材质四项覆盖）+ 编号速查。

## 框架

框架本身见 [FRAMEWORK.md](FRAMEWORK.md)：12 维决策归属、三层架构（基础资产库 → 任务模板库 →
成品案例库）、组合顺序、冲突裁决、参考图使用规则、商品信息母版、六阶段建设路线图。

一句话记忆：**form / goal / category / style 是你定的；shot / people / scene / material / light /
layout 是派生的；spec 是平台铁律，谁都不能碰。**

## 结构

```
FRAMEWORK.md          一级框架 V3（唯一的设计文档）
data/*.json           十二维条目 + conflicts 冲突规则 + cases 验证案例 + templates 任务模板 + palettes 配色参考
gallery/              实测出图落点（文件名=卡片 id，JPG/PNG/WebP 都认——页面自动探测扩展名，换图刷新即读，无需同步）
assets/data-bundle.js 派生物（tools/build_web.js 生成，勿手改）
assets/engine.js      引擎副本（tools/compose.js 同步而来，勿手改）
index.html            八页单页应用（纯静态，双击即用；配方盘/成品/全部词条集中在合成器一页）
tools/compose.js      ★ 引擎单一真源：装配/冲突/算子/随机/商品信息/母版/批量/盘点，页面与 CLI 共用
tools/build_web.js    重建 data-bundle + 同步 engine.js
tools/check_fields.js 字段体检（id/空字段/prompt 禁中文/中英串味/坏字符/配色卡校验）
tools/check_cases.js  引用体检 + 12 维覆盖矩阵 + 模板校验
tools/smoke.js        引擎冒烟（Node 直跑，无需 jsdom）
tools/smoke-web.js    界面冒烟（jsdom，111 项）
tools/inventory.js    盘点 + 覆盖缺口
tools/show_prompt.js  CLI 查配方（--case / --template / --random / --operator / --batch / --product）
tools/gallery_sync.js 画廊同步 + 体检（--check）
tools/gallery_watch.js 画廊守夜人（双击 tools/gallery_watch.bat：换图自动同步清单）
```

## 命令

```bash
node tools/build_web.js    # 改完 data/*.json 必跑（重建派生 bundle + engine）
node tools/check_fields.js && node tools/check_cases.js   # 两项体检
node tools/smoke.js        # 引擎冒烟
NODE_PATH=<jsdom> node tools/smoke-web.js   # 界面冒烟
node tools/inventory.js    # 规模与缺口
node tools/show_prompt.js --case CS-01      # CLI 直接看案例配方
node tools/show_prompt.js --batch --spec SP-08 --category CT-01   # CLI 批量五图型
```

## 已知边界

- 提示词条目是视觉观察 + 通用摄影常识（seen），**未经模型逐条实测**（案例 tested=false）——
  按路线图阶段四，用真实商品测完回填再宣称有效。
- 平台尺寸规则以各平台官方文档为准，改版后需人工核对。
- 中文长文案建议后期排版叠加，不要让模型直出长文字。
- 人物出镜（尤其婴幼儿）注意肖像与未成年人保护合规。
- 配色卡的 hex 是搭配起点不是品牌规范——真实品牌色以客户 VI 为准。
